# Divers manip dataset maisons 🏚️

## Étape 1 : Installation des dépendances

Avant d'exécuter le script, vous devez installer les bibliothèques Python requises. Elles sont listées dans le fichier `requirements.txt`. Installez cela dans un env Python dans le dossier du projet préalabelemnt cloné :

```powershell
   https://github.com/tangmomb/Data_maisons.git
```

1. Ouvrez un terminal ou une invite de commande.
2. Placez vous dans le répertoire du projet.
3. Exécutez la commande suivante pour installer les dépendances (assurez-vous d'avoir Python et pip installés) :

   ```powershell
   pip install -r requirements.txt
   ```

   Cela installera toutes les bibliothèques nécessaires, comme pandas, scikit-learn, etc., si elles ne sont pas déjà présentes.

## Étape 2 : Exécution des scripts

Une fois les dépendances installées, vous pouvez lancer les scripts.

1. Dans le même terminal, exécutez la commande suivante :

   ```powershell
   python nom_du_script.py
   ```
